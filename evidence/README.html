Reproducible evidence for the security assessment

This folder holds the reproducible evidence produced during the audit and the implemented security improvement. Nothing here contains API keys, tokens, passwords, connection strings, real database contents or personal data.

1. What was verified

  • Baseline test suite (tests/test_smoke.py): 26 passed at commit 90a5076.
  • After the request-body-limit fix (tests/test_smoke.py + tests/test_request_limits.py): 32 passed.
  • New regression tests: 6 tests in tests/test_request_limits.py covering normal, oversized, at-limit, negative, invalid and missing Content-Length handling.
