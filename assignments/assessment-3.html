LO3 · design decisions, implementation and security testing

Assessment 3 — Secure design and implementation

Apply the identified risks to produce a secure design, implement the corresponding controls, and demonstrate their effectiveness with documented testing.

Complete LO3
The controls implemented are traced to the risks they mitigate, and each is evidenced by a reproducible test rather than an assertion. Where a control could not be implemented in the time available, the gap is recorded explicitly in the risk register.

Assessment

  • Secure design Complete

    Design decisions for the security controls, each traced to the risk it addresses.

    • Control-to-risk traceability
    • Secure design principles applied
    • Rejected alternatives and the reason

  • Implementation Complete

    How each control was implemented, with the code locations where the change was made.

    • Per-control implementation notes
