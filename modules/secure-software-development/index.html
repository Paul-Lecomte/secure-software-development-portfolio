Secure Software Development

MSc Computer Science · University of Essex Online

Units

Twelve units make up this module. Each unit has its own page with assignments and artefacts.

Unit 1 — Introduction to Secure Software Development

Core concepts — Foundations of secure development

Fundamentals of secure software development, security mindset, and the importance of building security in from the start.

View unit →

Unit 2 — UML Modelling to Support Secure System Planning

Design — UML and security modelling

Using UML diagrams to model secure systems, including misuse cases, sequence diagrams, and security requirements.

View unit →

Unit 3 — Programming Languages: History, Concepts & Design

Concepts — Language design and security implications

Exploring programming language history, concepts, and how language design choices affect software security.

View unit →

Unit 4 — Exploring Programming Language Concepts

Practical — Hands-on language feature analysis

Practical exploration of programming language features including buffer overflows, memory safety, and stack protection mechanisms.

View unit →

Unit 5 — An Introduction to Testing

Verification — Testing fundamentals

Introduction to software testing principles, test types, and their role in secure software development.

View unit →

Unit 6 — Using Linters to Support Python Testing

Tools — Static analysis and linting

Using linting tools and static analysis to improve Python code quality and catch security issues early.

View unit →

Unit 7 — Introduction to Operating Systems

Systems — OS security fundamentals

Operating system concepts relevant to security, including processes, memory management, and access control.

View unit →

Unit 8 — Cryptography and Its Use in Operating Systems

Cryptography — Applied crypto in OS

Cryptographic primitives and their application in operating systems for confidentiality, integrity, and authentication.

View unit →

Unit 9 — Developing an API for a Distributed Environment

Architecture — Distributed systems and APIs

Designing secure APIs for distributed systems, including authentication, authorization, and communication security.

View unit →

Unit 10 — From Distributed Computing to Microarchitectures

Advanced — Microarchitectural security

Evolution from distributed computing to microarchitectures, covering side-channel attacks and hardware-level security.

View unit →

Unit 11 — Future Trends in Secure Software Development

Research — Emerging trends and technologies

Exploring future trends including AI in security, quantum-resistant cryptography, and evolving threat landscapes.

View unit →

Unit 12 — Code Demonstrations & Concluding our Study

Capstone — Practical demonstrations and summary

Code demonstrations showcasing secure development practices and concluding our study of secure software development.

View unit →
