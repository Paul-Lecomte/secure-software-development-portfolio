Secure Software Development

MSc Computer Science · University of Essex Online

Units

Twelve units make up this module. Each unit has its own page with assignments and artefacts.

Unit 1 — Foundations

Core concepts — Security foundations

Introduction to secure software development principles, terminology, and the security mindset.

View unit →

Unit 2 — Security Principles

Core concepts — Principles and models

Fundamental security principles: CIA triad, defense in depth, least privilege, fail-safe defaults.

View unit →

Unit 3 — Threat Modeling

Analysis — STRIDE and attack trees

Systematic threat identification using STRIDE, attack trees, and data flow diagrams.

View unit →

Unit 4 — Risk Assessment

Analysis — Risk identification and evaluation

Risk assessment methodologies, qualitative and quantitative analysis, risk registers.

View unit →

Unit 5 — Secure Design

Design — Architecture and patterns

Secure architecture patterns, trust boundaries, security controls, and design reviews.

View unit →

Unit 6 — Secure Implementation

Implementation — Coding practices

Secure coding standards, input validation, output encoding, and language-specific pitfalls.

View unit →

Unit 7 — Security Testing

Verification — Testing strategies

Static analysis, dynamic testing, penetration testing, fuzzing, and test automation.

View unit →

Unit 8 — Security Operations

Operations — Monitoring and response

Logging, monitoring, incident response, vulnerability management, and patch management.

View unit →

Unit 9 — Cryptography

Specialist — Applied cryptography

Symmetric and asymmetric encryption, hashing, digital signatures, key management, TLS.

View unit →

Unit 10 — Secure Deployment

Deployment — CI/CD and infrastructure

Secure build pipelines, container security, infrastructure as code, secrets management.

View unit →

Unit 11 — Compliance and Governance

Governance — Standards and regulations

Security frameworks (ISO 27001, NIST), compliance requirements, audit and assurance.

View unit →

Unit 12 — Professional Practice

Professional — Ethics and development

Professional ethics, continuous learning, security culture, and career development.

View unit →
