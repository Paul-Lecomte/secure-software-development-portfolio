Secure Software Development e-Portfolio

A security-assessed case study of a Python transit-routing backend (RAPTOR pathfinding, gRPC + HTTP, Neo4j) and its supporting full-stack system, SwissTransitMap. Built as summative assessment evidence for the Secure Software Development module.

Technical case study

Python routing backend: HTTP request parsing, gRPC service, Neo4j access, environment configuration, input bounds, caching, exception handling, logging, dependencies, tests, Docker/CI.

Security audit

STRIDE threat model, risk register, source-level observations with file/line references, confirmed vs. potential findings, recommended mitigations.

Implemented improvement

Request-body size ceiling (1 MiB) on the HTTP /path endpoint with 413 response and regression tests.

Professional development

Reflection, skills matrix, PDP, meeting-note and feedback templates (missing evidence transparently flagged).

Audit summary

Repositories inspected:

  • fastest_path_backend — commit 90a5076 (17 July 2026). Python 3.12.10, gRPC 1.78.0, Neo4j 6.1.0, Numba 0.64.0, NumPy 2.4.3. 26 smoke tests pass.
  • swiss-pb-map — commit 610e434 (13 February 2026). Next.js 16/React 19 frontend, Express/Node.js backend, MongoDB, Mongoose, JWT, bcrypt, Helmet, CORS.

Date of audit: 21 October 2026. Line references in the docs/ section are pinned to the commit SHAs shown above and are machine-verified by tools/verify_references.py.

How to read this portfolio. The docs/ section contains the assessed artefacts: learning-outcome mapping, system overview, threat model, risk register, secure design, implementation notes, security-testing results, and critical evaluation. The discussions/ and professional-development/ sections contain structured templates for collaborative discussion summaries, reflection, meeting notes, feedback, skills matrix and PDP — these are intentionally unpopulated where genuine evidence (discussion posts, peer/tutor feedback, meeting attendance) has not yet been supplied, in line with the requirement not to fabricate collaboration.
